# Focus Tab Groups

[English](README.md) | **Русский**

Переключайтесь между группами вкладок Obsidian по номеру с помощью настраиваемых горячих клавиш.

Плагин добавляет команды для прямого перехода к группам вкладок — аналогично навигации по группам вкладок в IDE, таких как Visual Studio Code.

## Возможности

- Переключение между группами вкладок 1–9
- Визуальная нумерация групп
- Настройка через раздел горячих клавиш Obsidian
- Отсутствие предустановленных сочетаний клавиш
- Боковые панели не учитываются при нумерации групп

## Использование

После включения плагина откройте:

`Настройки → Горячие клавиши`

Найдите:

`Focus tab group`

Плагин добавляет следующие команды:

- Focus tab group 1
- Focus tab group 2
- Focus tab group 3
- ...
- Focus tab group 9

Назначьте им удобные сочетания клавиш.

Например:

```text
Ctrl+1 → Группа вкладок 1
Ctrl+2 → Группа вкладок 2
Ctrl+3 → Группа вкладок 3
```

Эти сочетания удобно использовать вместе с отдельными горячими клавишами для выбора вкладок внутри текущей группы.

Например:

```text
Ctrl+1 → Группа 1
Ctrl+2 → Группа 2
Ctrl+3 → Группа 3

Alt+1 → Вкладка 1 в текущей группе
Alt+2 → Вкладка 2 в текущей группе
Alt+3 → Вкладка 3 в текущей группе
```

## Нумерация групп

Группы вкладок нумеруются в соответствии с их визуальным расположением.

Порядок нумерации:
1. Слева направо
2. Сверху вниз

Пример:
```text
┌──────────────┬──────────────┐
│   Группа 1   │   Группа 2   │
├──────────────┼──────────────┤
│   Группа 3   │   Группа 4   │
└──────────────┴──────────────┘
```

Учитываются только группы в основной рабочей области редактора.

Левая и правая боковые панели Obsidian игнорируются.

При переходе к группе плагин фокусирует вкладку, которая уже выбрана в этой группе.

# Установка

## Через менеджер плагинов Obsidian

1. Откройте в Obsidian `Настройки → Сторонние плагины`
2. Нажмите **Обзор**
3. Найдите **Focus Tab Groups**
4. Выберите плагин и нажмите **Установить**
5. После установки нажмите **Включить**

## Ручная установка

Скачайте следующие файлы из последнего релиза на GitHub:
- `main.js`
- `manifest.json`

Создайте следующий каталог внутри вашего хранилища:
```text
<путь>/<к>/<хранилищу>/.obsidian/plugins/focus-tab-groups/
```

Скопируйте в него скачанные файлы:
```text
.obsidian/
└── plugins/
    └── focus-tab-groups/
        ├── main.js
        └── manifest.json
```

Перезапустите Obsidian.

Затем откройте `Настройки → Сторонние плагины` и включите **Focus Tab Groups**.

# Разработка

Требования:
- Node.js
- npm

Клонируйте репозиторий и установите зависимости:
```bash
git clone https://github.com/raykotarou/focus-tab-groups-obsidian.git
cd focus-tab-groups-obsidian
npm install
```

Запустите сборку в режиме разработки:

```bash
npm run dev
```

Создайте ПРОД-сборку:

```bash
npm run build
```

Запустите линтер:

```bash
npm run lint
```

ПРОД-сборка создаёт файл `main.js` в корне проекта.
